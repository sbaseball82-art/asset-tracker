# memory10 データ収集ノート

対象：世界メモリ大手の業績推移（2016〜2025年の10期）比較動画用データセット。

## 確定した前提（ユーザー承認済み・2026-08-20）

- **対象は8社**。非上場の YMTC / CXMT は公式開示が存在せず third-party 推計しか無いため除外し、
  全数値を公式開示ベースで揃えることを優先した。
- **Samsung は3指標すべて DS部門（半導体全体）ベース**。メモリ単独の営業利益が非開示のため、
  指標間で定義がブレないよう売上高も DS部門で統一する。画面には常時「※DS部門」注記を出す。
- **SanDisk は WDフラッシュ事業 → SanDisk を1本の線として接続**。分社年に区切りマーカーを入れる。

## 年次マッピング規則

決算月が **6月以降**のFYはその暦年へ、**5月以前**のFYは前暦年へ寄せる。

| 企業 | 決算月 | 例 |
|---|---|---|
| Samsung / SK hynix / 台湾3社 | 12月 | FY2025 → 2025年 |
| Micron | 8月 | FY2025（2025年8月期）→ 2025年 |
| SanDisk / WD | 6〜7月 | FY2016（2016年7月期）→ 2016年 |
| Kioxia | 3月 | 2026年3月期 → 2025年 |

## 未解決：この環境から公式開示にアクセスできない

このセッションの egress ポリシーは npm / PyPI 等のパッケージレジストリのみを許可しており、
`www.sec.gov`・各社IRサイト・Wikipedia を含む外部サイトはすべてブロックされる
（`WebFetch` も同じプロキシを通るため回避不可）。
そのため **10-K / 有価証券報告書 / IR資料を開いて数値と参照箇所を確認できない**。

検索スニペット経由で数字を並べることは可能だが、それは「開けなかったURLを出典として記録する」
ことになり、本リポジトリの方針（推測値で埋めない・出典を1件ずつ記録する）を満たさない。
よって **数値セルは全て未記入のまま**とし、値の充填はネットワークが開通した環境で行う。

## 構造的な欠損（ネットワークが開通しても埋まらない）

1. **SanDisk の営業利益 2016〜2022**
   Western Digital は FY2023 まで単一報告セグメント。FY2024 に Flash / HDD の2セグメントへ
   移行したが、セグメント開示は**売上高と売上総利益（gross profit）まで**で営業利益は無い。
   SanDisk 単体の営業利益が取れるのは分社後の 10-K（FY2025、carve-out で FY2024・FY2023 まで遡及）のみ。
   → 営業利益・営業利益率の線は 2016〜2022 が null になる。
   （参考値：FY2024 Flash 売上 $6,687M / 粗利 $1,079M、FY2023 $6,063M / $433M、FY2022 $9,753M / $3,527M）

2. **Kioxia の 2016〜2017年度**
   東芝メモリの分社は2017年4月、東芝からの独立は2018年6月。それ以前はキオクシアという
   法人が存在せず、遡及開示も無い。東芝の半導体セグメントは NANDメモリ以外を含むため代用できない。
   → 2016年・2017年は null になる可能性が高い。

3. **Samsung のメモリ単独営業利益**
   全期間で非開示。上記のとおり DS部門で代替する（欠損ではなく定義の差として注記する）。

4. **Winbond の全社連結**
   メモリ以外のファウンドリ受託を含む。メモリ単独のセグメント開示は無い。

## ファイル

| ファイル | 内容 |
|---|---|
| `data/specs/memory10.yml` | 企業・指標・文言・配色の定義（ここが原本） |
| `data/memory10.csv` | long形式の本体（company × metric × year = 240行）。値は未記入 |
| `data/memory10.json` | spec から生成したメタデータ（Remotion側も読む） |
| `data/fx_rates.csv` | 期中平均レート（全データセット共通）。通貨×基準×年で引く |

為替は通貨だけでなく**基準**でも引く。キオクシアは4月〜3月の年度平均、
それ以外の会社は暦年平均を使うため、同じJPYでも行が分かれている。

`operating_margin` は入力せず `operating_income / revenue * 100` で導出する
（`derived=TRUE`）。売上高か営業利益のどちらかが null の年は営業利益率も null。

## 実データを入れたときに効いてくる懸念：縦軸のレンジ差

サムスンDS部門は2025年におそらく800〜900億ドル規模、旺宏電子は10億ドル前後。
**線形の縦軸だと下位3社（南亞・華邦・旺宏）が0付近の平らな線になって区別がつかない。**
ダミー実行でもすでにその兆候が出ている。

選択肢：

1. 線形のまま出す（依頼どおり）。上位5社の物語として割り切る
2. 売上高・営業利益だけ対数軸にする。桁違いの比較には適するが、
   「2倍に見えるが実は10倍」という誤読を生むので軸に明示が要る
3. 下位3社を外して5社にする
4. 営業利益率（③）は比率なので桁差が出ない。ここが一番きれいに8社並ぶ

どれを採るかは数値が揃ってから判断したほうがよい（実際の差が確定してから）。
