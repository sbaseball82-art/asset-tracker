# 投資ダッシュボードの使い方

## 最初にすること

PRの内容を確認してmainに取り込みます。GitHubの **Actions → daily-asset-slide →
Run workflow** を押すと、翌朝を待たずに更新できます。

完成画像は `slide/dashboard.png`、ブラウザ用ファイルは `slide/dashboard.html` です。
GitHubのファイル画面からダウンロードし、HTMLをダブルクリックすると開きます。
スマートフォンでも表示幅に合わせて読めます。外部サーバーへの登録は不要です。

従来の `slide/slide.png` と `slide/allocation.png` は11商品の既存形式です。
12商品をまとめて見るときは新しい `dashboard.png` を使ってください。

## 毎朝の更新

日本時間の午前7時にGitHub Actionsの実行を予定しています。GitHub側の混雑で
遅れることがあるため、画像の更新日時・各商品の価格基準日を確認してください。
市場が休みの日には直近の取得可能な価格を使用します。

取得失敗時は確認済み価格を使って警告を表示します。初回から価格が取得できない
商品がある場合は、総資産を「未確認」とし、部分合計を正式な総資産にしません。
欠損がある場合はActionsも失敗表示になります。完全な履歴は別ファイルで保持します。
更新処理そのものが失敗した場合は前回のファイルが残るため、必ず更新日時も確認してください。

## 保有数量を変える

GitHubで `holdings.json` を開き、鉛筆マークから編集します。

- ETFは `etf` の各銘柄の株数。
- 投資信託は `fund` の各商品の口数。
- Fortinetは `stocks` → `FTNT` → `shares` の株数。
- 全売却は数量を0にします。項目自体は削除しないでください。

FTNTの `purchase_price_usd` は1株の取得単価（ドル）、`purchase_date` は
`"2026-01-15"` のような日付です。分からない項目は `null` のままにします。
円建て含み損益には取得時の為替 `purchase_usdjpy` も必要です。
複数回購入の場合は平均取得単価を入力してください。税金・手数料は含みません。
**編集した値は公開されます。** パスワードや証券口座情報は入力しないでください。

## 数字の意味

`portfolio.json` が12商品の統合データです。既存の `data.json` は従来機能のため
11商品のまま保持しています。

先週比・先月比・年初来は必要な基準日の履歴ができるまで「データ不足」です。
過去のFTNT取得日・価格を推測してグラフを作りません。既存履歴は保持しますが、
統合資産の履歴へ接続しません。

比較は、数量の変化を当日の価格で評価した「推定拠出」を差し引いた概算です。
実際の約定金額・時刻、配当、税金、手数料の記録がないため、正確な運用利回りでは
ありません。グラフの総資産増減には入出金を含むため、そのまま投資利益ではありません。

リスク分析は保有商品別の集中度、直接ドル建て資産の為替影響、投資対象の重複候補、
商品方針による米国市場依存、記録期間内の概算最大下落率を表示します。
投信内部の実際の国別比率・為替ヘッジ・企業別重複率は、十分なデータがない場合は
算定しません。最大下落率は欠損のない統合履歴が十分に蓄積された場合だけ表示します。

## 費用と未実装機能

Python、既存の無料価格取得先、標準のGitHub公開リポジトリ用runnerを使います。
新しい有料契約・APIキー・課金設定は追加していません。日次処理に有料AIのキーも
渡しません。ChatGPT PlusをAPIとして使う処理はありません。
既存のmorning-briefの任意AI整文とevergreenの任意AI提案も、Actionsから
有料AIキーを渡さないようにしています。既存の定型文・登録済みテーマは利用できます。

GitHubの保存容量・既存のアカウント課金設定や市場データの提供条件までは、コードから
保証できません。既存アカウントの利用状況を確認してください。無料枠を超える場合は
課金を有効にせず、画像の保存期間を短くするか自動実行を停止してください。

バックテストと仮想売買は今回未実装です。ユーザー指定の優先順位に従い、価格・計算・
画像・日次更新の安定化を優先しました。実注文を行う処理はありません。

## パソコンから更新する場合

Pythonを使う場合のコマンドです。GitHub Actionsだけで利用する方は不要です。

```bash
pip install -r requirements.txt
python -m playwright install chromium
python fetch_prices.py
python fetch_prices.py --portfolio
python make_dashboard.py
python make_slide.py
python make_allocation_slide.py
```

日本語フォント（Noto Sans CJK JP）が必要です。Actionsでは自動で導入します。
