# 統合ダッシュボードの変更計画

既存の `holdings.json` → `config.py` → `fetch_prices.py` → `data.json` →
従来2種類の画像生成と、既存のルックスルー・決算・投稿・週次処理を維持する。
ETF5商品・投信6商品の数量は変更しない。

調査で確認した問題：為替失敗時の架空の150円、年初の履歴がない場合の誤った
年初来表示、一部価格欠損による見かけの急落。確認済み価格または欠損表示に修正する。

1. `stocks`設定にFTNTを追加し、円換算・基準日・取得失敗を扱う。
2. `--portfolio`で12商品の`portfolio.json`を生成する。既存11商品のデータと
   分母を混ぜないため、`data.json`は従来の互換性を維持する。
3. 統合履歴は初回から新規に開始する。過去のFTNT保有履歴は推測しない。
4. 1920×1080の統合画像とレスポンシブHTMLを生成する。
5. 毎朝7時JST予定の既存Actionsに組み込む。
6. 計算・欠損・拠出調整・画像を検証する。
7. 計算可能な集中度・為替感応度などの分析を付ける。

利用者からFTNT数量・統合資産情報の公開許可を得たため、公開リポジトリに
保存する。認証情報・取得単価など未指定の値は作らない。

バックテストと仮想売買は、費用・配当・為替・約定時点・分割・ベンチマークを
検証する別PRの対象とする。今回、実際の発注・証券口座接続・有料APIは追加しない。
